# 🚚 Delivery Notes API — مذكرات التسليم

## ما هي مذكرة التسليم؟

مذكرة تسليم = **مستند** يُثبت تسليم بضاعة للعميل **قبل** إصدار الفاتورة.

**الفرق عن الفاتورة:**
- المذكرة = تسليم بضاعة (بدون قيد محاسبي)
- الفاتورة = بيع فعلي (مع قيد محاسبي)

**متى نستخدمها؟**
- موزع جملة: يسلم بضاعة، ثم يصدر فاتورة نهاية الشهر
- تجاري: يسلم قبل الدفع
- صيدلية: نادراً ما تُستخدم (الفاتورة فورية)
